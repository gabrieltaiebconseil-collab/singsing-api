# Sing Sing Keyboard Extension

Native keyboard extensions for iOS and Android. These run as separate processes
and must be compiled with native tooling (Xcode / Android Studio).

## iOS Keyboard Extension

### Setup
1. Open the Xcode project generated by `npx expo prebuild`
2. Add a new target: File → New → Target → Custom Keyboard Extension
3. Replace the generated `KeyboardViewController.swift` with `ios/KeyboardViewController.swift`
4. Copy `ios/Info.plist` to the extension target
5. Enable "RequestsOpenAccess" for network access
6. Set the deployment target to iOS 15+

### Key Details
- Extension height: 320px
- API base: `https://singsing-production.up.railway.app`
- URL scheme: `singsing://` to open main app
- Memory limit: 30MB (iOS enforced)

## Android Input Method

### Setup
1. Run `npx expo prebuild` to generate the Android project
2. Add `keyboard-extension/android/` as a module in `settings.gradle`
3. Copy `SingSingInputMethodService.kt` to the module's source directory
4. Add `res/xml/method.xml` for IME configuration
5. Merge `AndroidManifest.xml` entries into the app manifest

### Key Details
- Service: `SingSingInputMethodService` extends `InputMethodService`
- Input view height: 320dp
- Uses coroutines for async API calls
- URL scheme: `singsing://` to open main app

## Testing
- iOS: Settings → General → Keyboard → Keyboards → Add → Sing Sing
- Android: Settings → System → Languages & Input → On-screen keyboard → Manage → Sing Sing

## Architecture
```
User types in WhatsApp/iMessage/etc.
    ↓
Switches to Sing Sing keyboard
    ↓
Searches for a song (API call)
    ↓
Taps CLIP → opens Sing Sing main app
    ↓
User selects lyrics, creates clip
    ↓
Native share sheet sends clip back
```
